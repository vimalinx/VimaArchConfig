Action Desk 的 Todo 面板是写给键盘党用的，双手不用离开主键位区 ⌨️

封面是按真实配色画的三栏布局示意（今天 / 本周 / 本月+长期），不是截图。

**移动焦点**

- `hjkl` 或方向键上下左右
- `g` / `G` 跳到栏顶 / 栏底

**整理任务**

- `Ctrl+hjkl` 调顺序，或者直接把任务挪到别的桶（今天 → 本周 → 本月 → 长期）
- `m` 再按 `t` / `w` / `m` / `l`：直接指定时段（今天/本周/本月/长期）
- 子项跟随父项时段，移动子项会被拦下并提示「请移动父 Todo」

**增删改**

- `i` 输入新任务，落到当前焦点所在的栏
- `Tab` 给当前任务建子项，`Space` 展开 / 折叠子任务
- `Enter` 或 `x` 完成，`dd` 删除，`yt` 复制标题

一个我很喜欢的小细节：新建任务时会检查同桶里有没有**相似标题**，有就提示「本周已有相似「xxx」」，防止同一件事记两遍 🔍

所有操作最终都落到 `vimalinx-todo` CLI（SQLite），面板只是个渲染层 —— 命令行和面板操作的是同一份数据。
